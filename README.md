# CoolMS sounds

The sounds CoolMS plays when something arrives, from one source, so the admin, the desktop workspace and the mobile
apps sound the same: one sound per kind of arrival (`ring`, `message`, `visitor`, `task`, `mail`, `bell`).

The sounds, their sources and the tools that make and encode them are on their way. This package publishes to no
registry; consumers take the files at a tag.
